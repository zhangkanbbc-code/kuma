# 性能优化队列

每项先采集真实数据的调用链和耗时，再修改并作前后对照；没有明确收益或破坏交互的试验撤回。完成回归后才处理下一项。

| 顺序 | 项目 | 状态 | 验收重点 |
| --- | --- | --- | --- |
| 1 | 主数据到达时重复构建任务名称索引 | 已完成，并已实机复核 | 644 个追踪器输出一致；处理约 378→146 ms |
| 2 | UI 偏好对象代理的逐属性同步 IPC | 已完成，并已实机复核 | 配置副本与跨窗口更新；启动长任务约 346→291 ms |
| 3 | 图鉴离屏目录行与滚动位置保存相互触发布局 | 已完成，并已实机复核 | 隔离排版总耗时约 440→312 ms；实机首见回调 124→94 ms；滚动与宽窄切换通过 |
| 4 | 启动基线读取、改造图索引、隐藏面板和重复布局保存 | 已完成隔离验证，待实机复核 | 最大渲染任务 305–311→183–192 ms；改造图结果一致；面板首次打开与持久化通过 |
| 5 | 资料在途请求、译名反查与同句译文索引 | 已完成隔离验证 | 同 ID 重复请求归零，53→45 次；6504 个名称反查和 14765 项译文索引一致 |
| 6 | 抬头自适应、指标条测量的剩余开销 | 已评估，按性价比停止 | 一次性启动与缩窄窗口排版仍有开销；继续细化需要更多测量缓存/布局改造，当前收益不足 |
| 7 | 正常使用中的补丁批次、持续运行与资源占用 | 已完成本轮压力与回收核对，停止扩展 | 重复母港及 3 批变化型资源/任务报文处理很快；回收后的主、渲染堆没有显示持续累计 |

停止条件为“若没有可优化或者只剩性价比中下的则停下”。已确认的高收益项完成，剩余候选当前不具备足够投入产出比，因此本轮停止，不再循环扩展优化。最新源码已通过验证，下次从开发入口启动时载入。详细数据见 [启动性能记录](startup-performance.md)。
